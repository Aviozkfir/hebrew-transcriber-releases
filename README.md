# Hebrew Telephone Transcription: releases

Download **hebrew-transcriber.zip** from the [latest release](https://github.com/Aviozkfir/hebrew-transcriber-releases/releases/latest), unzip it and run `start.bat`.
To update an installed copy, copy the new files into its folder and choose Replace: recordings, transcripts and the API key are kept.

This repository only holds builds; the source is private.
